Fluxent¶

XtkHost *flux_host_create(void)¶

flux_host_destroy frees the context and store this creates.

XtkHost *flux_host_adopt(XentCtx *ctx, FluxStore *store, XentNodeId root)¶

Does not take ownership of ctx or store.

XtkSubId flux_host_subscribe(XtkHost *host, XtkCtrl target, XtkEventId event, uint32_t phases, XtkEventFn fn, void *userdata)¶

Borrows userdata until flux_host_unsubscribe or flux_host_destroy.

XtkResource flux_image_respath(const char *path)¶

Copies path. The caller may free it. The id remains valid for the rest of the process.

void flux_app_onframe(FluxApp *app, void (*cb)(void *ctx), void *ctx)¶

Borrows ctx until this callback is replaced or the app is destroyed.

bool flux_app_invoke(FluxApp *app, void (*fn)(void *ctx), void *ctx)¶

Borrows ctx until fn runs on the window thread.

XtkPostStatus flux_app_poststring(FluxApp *app, XtkMsg msg, const char *data, uint32_t len)¶

Copies data and delivers it on the window thread. The caller may free data. len > 0 with NULL data is rejected.

bool flux_data_settext(FluxData *data, const char *utf8, size_t len)¶

Copies utf8. The caller may free it.

bool flux_data_setfiles(FluxData *data, const char *paths)¶

Copies paths. The caller may free it.

bool flux_data_setbitmap(FluxData *data, const FluxBitmap *bitmap)¶

Copies bitmap->pixels. The caller may free them.

bool flux_data_setcustom(FluxData *data, const char *format, const void *bytes, size_t len)¶

Copies bytes. The caller may free them.

char *flux_data_text(const FluxData *data)¶

malloc’d UTF-8. The caller frees it.

char *flux_data_files(const FluxData *data)¶

malloc’d UTF-8, one path per line. The caller frees it.

bool flux_data_bitmap(const FluxData *data, FluxBitmap *out)¶

Copies pixels into out. The caller frees out->pixels.

void *flux_data_custom(const FluxData *data, const char *format, size_t *len)¶

malloc’d bytes. The caller frees the pointer. *len is the byte count.

FluxData *flux_clipboard_get(void)¶

Owned. The caller destroys it.

bool flux_clipboard_settext(const char *utf8, size_t len)¶

Copies utf8. The caller may free it.

char *flux_clipboard_text(void)¶

malloc’d UTF-8. The caller frees it.

const FluxData *flux_drag_data(void)¶

Borrowed, and only while a drag or drop callback is running.

char *flux_filedialog_show(FluxApp *app, const FluxFileDialogDesc *desc)¶

malloc’d UTF-8, one path per line. NULL if cancelled. The caller frees it.

XtkPostStatus flux_filedialog_post(FluxApp *app, const FluxFileDialogDesc *desc, XtkMsg reply)¶

Copies the strings in desc. The caller may free them. The chosen paths are posted as one UTF-8 path per line.
