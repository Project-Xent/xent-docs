xent-kit¶

bool xtk_batch_set(XtkBatch *batch, XtkNodeRef target, XtkPropertyId id, XtkValue value, XtkChangeStamp change)¶

Copies string and bytes. The caller may free them. len > 0 with a NULL pointer fails and appends nothing. A resource id is copied; res_retain is not called.

XtkSubRef xtk_batch_on(XtkBatch *batch, XtkNodeRef target, XtkEventId event, uint32_t phases, XtkEventFn fn, void *arg)¶

Borrows arg until unsubscribe or the host is destroyed.

struct XtkValueView¶

string and bytes point at the host’s stored copy, until that property changes or the host is destroyed.

struct XtkEventPayload¶

string and query.text are valid only for the duration of the callback.

XtkPostStatus xtk_rt_post(XtkRt *rt, XtkMsg msg)¶

Must run on the thread that created rt.

XtkPostStatus xtk_rt_poststring(XtkRt *rt, XtkMsg msg, const char *data, uint32_t len)¶

Must run on the thread that created rt. Copies data; the caller may free it. len > 0 with NULL data is rejected.
