API 参考¶

以下 C API 参考由 Hawkmoth 直接从同级源码仓库的公开 C23 头文件生成。声明注释标明了所有权、 NULL 处理、借用生命周期、线程规则与错误行为。

  • xent-core —— 无头布局、节点树、固有尺寸/文本测量与显示列表（ <xent/xent.h> ），用于开发自定义宿主或无头排版管线。

  • xent-kit —— 原子化 XtkBatch 协议、保留式 XtkHost ABI、事件载荷与协调器运行时（ <xtk/...> ）。声明式元素构建器声明于 <xtk/xtk.h> ，自动生成的命令式控件包装函数声明于 <xtk/xtk_controls.h> 。

  • Fluxent —— Windows 原生应用入口（ flux_run 、 FluxApp ）、 XtkHost 挂载、窗口管理、菜单、弹出层、文件对话框、剪贴板与拖放接口（ <fluxent/...> ）。
