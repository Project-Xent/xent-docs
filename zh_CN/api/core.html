xent-core¶

XentNodeId xent_node_create(XentCtx *ctx)¶

生命周期观察者正在执行期间调用将返回失败。

bool xent_node_destroy(XentCtx *ctx, XentNodeId node)¶

销毁整棵子树。生命周期观察者正在执行期间调用将返回失败。

bool xent_node_append(XentCtx *ctx, XentNodeId parent, XentNodeId child)¶

将 child 从当前父节点分离并追加到 parent 末尾。观察者执行期间或 child 为 parent 祖先时返回失败。

bool xent_node_remove(XentCtx *ctx, XentNodeId parent, XentNodeId child)¶

生命周期观察者正在执行期间调用将返回失败。

bool xent_node_insert(XentCtx *ctx, XentNodeId parent, XentNodeId child, XentNodeId before)¶

当 before == XENT_NODE_INVALID 时追加到末尾。要求 child 尚无父节点；观察者执行期间或 child 为 parent 祖先时返回失败。

bool xent_node_move(XentCtx *ctx, XentNodeId parent, XentNodeId child, XentNodeId before)¶

当 before == XENT_NODE_INVALID 时移至末尾。要求 child 已位于 parent 之下；观察者执行期间返回失败。

bool xent_node_reparent(XentCtx *ctx, XentNodeId new_parent, XentNodeId child, XentNodeId before)¶

当 before == XENT_NODE_INVALID 时追加到末尾。要求 child 原先挂在另一个父节点下；观察者执行期间或 child 为 new_parent 祖先时返回失败。

XentObsId xent_node_addobs(XentCtx *ctx, const XentNodeObs *observer)¶

借用 observer->userdata 直至调用 xent_node_delobs 或 xent_ctx_destroy 。

bool xent_sem_setlabel(XentCtx *ctx, XentNodeId node, const char *label)¶

拷贝 label （传入 NULL 时存为空字符串），调用方随后可释放原缓冲区。

const char *xent_sem_label(const XentCtx *ctx, XentNodeId node)¶

借用指针有效至该节点下一次调用 xent_sem_setlabel 或节点销毁为止。

const char *xent_node_text(const XentCtx *ctx, XentNodeId node)¶

借用指针有效至该节点下一次调用 xent_settext 或节点销毁为止。

bool xent_settext(XentCtx *ctx, XentNodeId node, const char *text)¶

拷贝 text （传入 NULL 时存为空字符串），调用方随后可释放原缓冲区。

bool xent_setfontfamily(XentCtx *ctx, XentNodeId node, const char *family)¶

拷贝 family （传入 NULL 或 "" 清空设置），调用方随后可释放原缓冲区。

bool xent_settextruns(XentCtx *ctx, XentNodeId node, const XentTextRun *runs, uint32_t count)¶

拷贝 runs 数组及每个 font_family 字符串，调用方随后可释放输入缓冲区。

bool xent_node_setmeasure(XentCtx *ctx, XentNodeId node, XentExternalMeasureFn fn, void *userdata)¶

借用 userdata 直至调用 xent_node_clearmeasure 或节点销毁。

bool xent_dl_drawtext(XentDlBuilder *b, XentRect bounds, const char *utf8, float font_size, uint16_t font_weight, XentColor color)¶

拷贝 utf8 字符串，调用方随后可释放原缓冲区。

bool xent_dl_drawtextstyle(XentDlBuilder *b, XentRect bounds, const char *utf8, const XentTextStyle *style, XentColor color)¶

拷贝 utf8 字符串，调用方随后可释放原缓冲区。

XentDl *xent_dl_end(XentDlBuilder *b)¶

消费并结束构建器 b （即使仍有未闭合的裁剪、变换或透明度压栈状态）。

const char *xent_dl_text(const XentDl *list, uint32_t offset, uint32_t len)¶

返回指向 list 内部的只读指针，有效至调用 xent_dl_free 为止。
