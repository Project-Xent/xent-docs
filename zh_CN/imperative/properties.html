3. 强类型构建器、属性位掩码与布局¶

<xtk/xtk_controls.h> 直接由 xent-kit/tools/catalog.lua 生成，为全部 70 余种控件提供强类型创建结构体、单属性设置函数与事件订阅包装函数。

<xtk/xtk_controls.h> 命名规律¶

目录中的每种控件 <ctrl> （如 container 、 card 、 scroll 、 text 、 button 、 checkbox 、 slider 、 textbox 、 combo 、 list 、 nav 、 dialog 、 commandbar ）均遵循统一的生成命名规则：

  • 属性结构体 ： Xtk<Ctrl>Props （例如 XtkButtonProps 、 XtkContainerProps 、 XtkTextBoxProps ）。

  • 属性掩码常量 ： XTK_<CTRL>_<PROP>_MASK （例如 XTK_BUTTON_TEXT_MASK 、 XTK_BUTTON_STYLE_MASK 、 XTK_BUTTON_W_MASK ）。

  • 事务内创建函数 ： XtkLocalId xtk_<ctrl>_create(XtkTxn *txn, XtkNodeRef parent, Xtk<Ctrl>Props const *props);

  • 运行期属性设置函数 ： bool xtk_<ctrl>_set<prop>(XtkScene *scene, XtkCtrl control, <type> value, XtkChangeStamp change);

  • 事件订阅函数 ： XtkSubRef xtk_<ctrl>_on<event>(XtkTxn *txn, XtkNodeRef target, XtkEventFn fn, void *arg);

公共布局字段—— w 、 h 、 grow 、 shrink 、 self （ XentFlexAlign ）、 ml / mt / mr / mb （外边距）以及 tip （工具提示文本）——直接内嵌在每种控件的 Xtk<Ctrl>Props 结构体中。

使用 .set 位掩码与字符串切片¶

在 C 复合字面量中，未填写的字段默认初始化为 0 ——而 0 同时也是 gap = 0.0f 、 sel = 0 或首个枚举值的有效取值。因此通过 .set 位掩码明确告知编码器本次要设置哪些字段：

XtkLocalId btn = xtk_button_create(
    &txn, parent,
    &(XtkButtonProps) {
        .set   = XTK_BUTTON_TEXT_MASK | XTK_BUTTON_ICON_MASK | XTK_BUTTON_STYLE_MASK,
        .text  = "Save",
        .icon  = "Save",
        .style = XTK_BUTTON_ACCENT,
    }
);

字符串长度规则¶

Xtk<Ctrl>Props 中的每个字符串属性都成对提供指针字段（如 .text 、 .icon 、 .placeholder 、 .tip ）与字节长度字段（ .text_len 、 .icon_len 、 .placeholder_len 、 .tip_len ），字符串 setter 函数同样接收 (char const *data, uint32_t len) ：

  • 以 NUL 结尾的普通 C 字符串 ：保持 .text_len = 0 （或在 xtk_<ctrl>_set<prop> 中传 len = 0 ）时，非空 data 会自动调用 strlen(data) 计算长度。

  • 显式字节切片与编译期字面量 ：传入非零长度可直接跳过 strlen 并支持无结尾符的 UTF-8 切片——例如对字面量定义 #define LIT(s) .text = s, .text_len = sizeof(s) - 1 ，或传入 (uint32_t) snprintf(...) 的返回值。

  • 批次在调用 xtk_*_create 与 xtk_*_set* 时会立即拷贝字符串内容，因此局部栈数组 char buf[64] 在调用返回后即可安全复用。

封装可复用的 Flex 布局辅助函数¶

将常用的纵列、横排、卡片与标签封装成几行辅助函数后，命令式布局代码同样紧凑易读（ fluxent/examples/gallery_imp/helpers.c 即采用此方式）：

static XtkLocalId ui_column(XtkTxn *txn, XtkNodeRef parent, float gap, XentFlexAlign align) {
    return xtk_container_create(
        txn, parent,
        &(XtkContainerProps) {
            .set   = XTK_CONTAINER_DIR_MASK | XTK_CONTAINER_ITEMS_MASK
                   | XTK_CONTAINER_GAP_MASK | XTK_CONTAINER_SHRINK_MASK | XTK_CONTAINER_FITH_MASK,
            .dir   = XTK_STACK_COLUMN,
            .items = align,
            .gap   = gap,
            .fith  = true,
        }
    );
}

static XtkLocalId ui_row(XtkTxn *txn, XtkNodeRef parent, float gap, bool wrap) {
    return xtk_container_create(
        txn, parent,
        &(XtkContainerProps) {
            .set   = XTK_CONTAINER_DIR_MASK | XTK_CONTAINER_ITEMS_MASK
                   | XTK_CONTAINER_GAP_MASK | XTK_CONTAINER_WRAP_MASK,
            .dir   = XTK_STACK_ROW,
            .items = XENT_FLEX_ALIGN_CENTER,
            .gap   = gap,
            .wrap  = wrap ? XENT_FLEX_WRAP : XENT_FLEX_NO_WRAP,
        }
    );
}

static XtkLocalId ui_card(XtkTxn *txn, XtkNodeRef parent, float gap, float pad) {
    return xtk_card_create(
        txn, parent,
        &(XtkContainerProps) {
            .set   = XTK_CONTAINER_DIR_MASK | XTK_CONTAINER_ITEMS_MASK | XTK_CONTAINER_GAP_MASK
                   | XTK_CONTAINER_PL_MASK | XTK_CONTAINER_PT_MASK | XTK_CONTAINER_PR_MASK | XTK_CONTAINER_PB_MASK,
            .dir   = XTK_STACK_COLUMN,
            .items = XENT_FLEX_ALIGN_STRETCH,
            .gap   = gap,
            .pl    = pad, .pt = pad, .pr = pad, .pb = pad,
        }
    );
}

XtkContainerProps 核心布局字段：

  • .dir ： XTK_STACK_COLUMN （纵向）或 XTK_STACK_ROW （横向）。

  • .items 与 .justify ：交叉轴 XentFlexAlign 对齐与主轴 XentFlexJustify 分布。

  • .pl 、 .pt 、 .pr 、 .pb ：左、上、右、下四边内边距。

  • .fill ：使容器拉伸填满父容器可用空间。

  • .fith / .fitw ：在滚动区域内使容器高度或宽度紧贴子元素测量尺寸。

通用属性读写与复合数据源函数¶

除按控件生成的包装函数外， <xtk/xtk_scene.h> 还提供与具体控件类型无关的通用操作：

  • 在多操作事务内批量修改属性 ：调用 xtk_txn_set(&txn, ref, XTK_PROP_WIDTH, (XtkValue) {.kind = XTK_VALUE_F32, .u.f32 = 240.0f}, (XtkChangeStamp) {0}) 可将跨多个控件的属性修改合并进同一次原子提交。

  • 读取当前属性值 ：调用 xtk_ctrl_get(&scene, ctrl, XTK_PROP_TEXT, &view, &stamp) 。 XtkValueView 内的字符串与字节切片直接指向宿主内部存储，有效至该属性下次变更或宿主销毁为止。

  • 填充复合子项集合 ：拥有结构化子项定义的控件在 <xtk/xtk_scene.h> 中配有专用事务设置函数：

    • xtk_txn_setitems(&txn, target, strings, count) （及运行期 xtk_ctrl_setitems ）——填充 ComboBox 、 AutoSuggestBox 、 BreadcrumbBar 或 LoopingSelector 的字符串列表。

    • xtk_txn_setselitems(&txn, target, selector_items, count) —— 填充带图标与文字的 SelectorBar 选项。

    • xtk_txn_settabs(&txn, target, tab_descs, count) —— 填充 TabView 标签栏。

    • xtk_txn_settree(&txn, target, &tree_desc) —— 填充 TreeView 层级树节点。

    • xtk_txn_setnav(&txn, target, &nav_desc) —— 填充 NavigationView 的导航项、分类头、分隔线、底部固定项以及一体化窗口标题栏配置。
