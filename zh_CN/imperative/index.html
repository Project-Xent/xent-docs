命令式开发指南¶

命令式路线 （ fluxent.imp ）赋予 C23 程序对保留式 XtkScene 、原子化 XtkTxn 事务、 <xtk/xtk_controls.h> 自动生成的强类型控件包装函数以及 XtkEventFn 路由事件回调的直接控制权。

命令式 API 同时也是 Xent 的稳定 C ABI 边界： oxent （Rust）、 zxent （Zig）、 xenthon （Python）与 hsxent （Haskell）均直接调用这组底层函数。

按顺序阅读以下六章，即可从基础窗口启动一路掌握 10 万行虚拟化集合与系统外壳集成：

  1. 1. 应用、宿主与场景生命周期 —— 初始化控件模块、 FluxApp 、 XtkHost 与 XtkScene ，拆解 fluxent.imp 模板并按规范顺序释放资源。

  2. 2. 原子事务与动态子树管理 —— 使用 XtkTxn 、 XtkNodeRef 、 XtkBatchResult 与 XtkBatchDiag 原子化构建、重排、重挂载并切换动态页面子树。

  3. 3. 强类型构建器、属性位掩码与布局 —— 掌握 <xtk/xtk_controls.h> 的 .set 属性位掩码、字符串长度约定、可复用的 Flex 布局辅助函数、通用属性读取与复合数据设置函数。

  4. 4. 事件路由、帧同步与变更戳 —— 订阅捕获/目标/冒泡阶段事件，解析各类 XtkEventPayload 载荷，通过 flux_app_onframe 合并帧内属性同步，并用 XtkChangeStamp 协调受控输入。

  5. 5. 命令式虚拟化列表与分组协议 —— 基于 XTK_EVENT_REALIZE 视口范围事件、行槽位复用与吸顶组标题，以命令式方式驱动 10 万行 ListView 与 GridView 。

  6. 6. 对话框、拖放、剪贴板与窗口集成 —— 控制模态 ContentDialog 、调用原生文件对话框、处理 FluxData 剪贴板与 OLE 拖放数据、定制窗口外观并从工作线程回调 UI 线程。
