Project Xent¶

Project Xent 是使用 C23 编写的原生跨平台 UI 技术栈（当前版本 0.3.3 ）。应用代码面向平台无关的控件协议编写，由底层原生宿主提供操作系统窗口、文本排版、输入处理与无障碍支持。

组件栈概览¶

Project Xent 由三个 C23 包组成。开发应用程序时，代码直接调用 xent-kit 与目标平台宿主（Windows 上为 fluxent ）：

应用层调用方式

核心职责

xent-core

作为底层依赖自动拉取

平台无关的布局引擎（Flex、Grid、SwiftStack、Absolute）、带代次校验的节点树、固有尺寸与文本测量缓存、语义树以及不可变显示列表。

xent-kit

<xtk/xtk.h> 或 <xtk/xtk_controls.h>

标准控件目录、原子化 XtkBatch 事务协议、命令式 XtkScene 接口，以及声明式 xtk_* 运行时。

fluxent

<fluxent/fluxent.h>

基于 Win32、Direct2D、DirectWrite、DirectComposition、UI Automation 与 cwinrt 构建的 Windows 10 1903+ 原生宿主，负责窗口管理、Fluent 控件渲染、Mica/Acrylic 背景材质、输入法（IME）、输入分发以及应用主循环（ flux_run / flux_app_run ）。

备注

官方 0.3.3 多语言绑定共享同一套控件目录与原生宿主： oxent （Rust）、 zxent （Zig）、 xenthon （Python 3.12+）与 hsxent （Haskell）。本手册介绍 C23 原生技术栈的用法。
