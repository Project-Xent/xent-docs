架构与核心概念¶

本页说明 Xent 0.3.3 中 xent-core 、 xent-kit 与 fluxent 的职责分层，以及保留式控件、可执行文件裁剪与后台线程通信的核心约定。

三层包职责划分¶

Project Xent 将布局计算、控件协议语义与操作系统原生渲染划分为清晰的三层：

  1. xent-core —— 无头布局引擎与显示列表

    • 维护带代次校验的 XentNodeId 节点树，即使节点槽位复用也能可靠识别过期句柄。

    • 负责 ABSOLUTE 、 FLEX 、 SWIFTSTACK 与 GRID 布局计算、固有内容测量、脏标记传播、焦点顺序、无障碍语义角色以及不可变 XentDisplayList 绘制指令列表。

    • 采用可移植 C23 实现，供各平台宿主、无头排版工具直接调用，并通过 xent-kit 导出共享布局类型（如 XentFlexAlign 、 XentInsets ）。

  2. xent-kit —— 控件协议、保留式宿主 ABI 与协调器

    • 定义由 tools/catalog.lua 生成的 70 余种标准控件目录、强类型属性与标准化事件。

    • 定义原子化变更编码格式 XtkBatch ：宿主在提交前对整批操作完成校验与准备，遇到任何错误时完整保留原有活动树状态。

    • 在该协议之上同时提供两套公开编程接口：命令式 XtkScene / XtkTxn API 与声明式 xtk_* 协调器。

  3. fluxent —— Windows 原生宿主

    • 基于 Win32、Direct2D、DirectWrite（文本塑形、字素级编辑、输入法）、DirectComposition 与 DirectManipulation（平滑滚动与 Mica/Acrylic 背景材质）、WIC（异步图像解码）、UI Automation（屏幕阅读器无障碍）以及 cwinrt （纯 C WinRT 投影）在 Windows 10 1903+ 上实现 XtkHost 。

    • 提供面向声明式应用的 flux_run 入口，以及面向命令式应用与桌面外壳集成（文件对话框、菜单、弹出层、拖放、剪贴板）的 flux_app_* 与 flux_host_* 接口。

保留式控件架构¶

无论采用声明式还是命令式，Xent 均运行在统一的 保留式（Retained） 控件架构之上：

  • Fluxent 宿主维护持久的原生控件实例，完整保留文本选区、输入法组字状态、键盘焦点导航、惯性滚动与系统无障碍节点。

  • 在声明式模式下， view() 在消息到达时于帧内存池中构造轻量描述节点，协调器将其与上一帧结构比对后，向现有控件提交增量 XtkBatch 补丁。

  • 事件驱动的帧调度使空闲窗口保持休眠，在用户输入、活动动画、异步图像解码完成或调用 flux_app_post / flux_app_redraw 时按需唤醒渲染。

模块化控件注册与体积裁剪¶

在 Fluxent 0.3.3 中，每种控件都封装为声明在 <fluxent/flux_controls.h> 中的独立 FluxControlModule （如 flux_ctrl_container 、 flux_ctrl_text 、 flux_ctrl_button 、 flux_ctrl_textbox 、 flux_ctrl_list ），配合链接器死代码消除，只将实际注册的控件编入最终程序：

  • 按需注册（ flux_controls_use(&flux_ctrl_<name>) ） ：逐个注册所需控件模块（每个模块会自动注册其内部依赖的子控件），未使用的控件代码会被链接器裁掉，使单文件可执行程序保持精简。

  • 全量注册（ flux_controls_all() ） ：一次调用注册全部内置控件模块，适合快速原型验证或使用大量控件的综合型应用。

重要

请在首次批次提交前完成所用控件模块的注册；创建未注册的控件类型会返回 XTK_BATCH_ERR_BACKEND 。

线程安全与后台任务¶

UI 树、 XtkScene 与 FluxApp 窗口运行在主 UI 线程上。执行网络请求、磁盘读写或计算任务的后台工作线程，通过 FluxApp 提供的线程安全投递函数将结果传回 UI 线程：

  • flux_app_post(app, xtk_msg_i(MSG_DONE, status)) —— 从任意线程将 XtkMsg 入队并唤醒窗口事件循环。

  • flux_app_poststring(app, xtk_msg(MSG_LOG), text, len) —— 拷贝 UTF-8 字符串并在 UI 线程上投递给 update() 。

  • flux_app_invoke(app, fn, ctx) —— 调度 fn(ctx) 到 UI 线程执行。
