快速开始¶

本指南介绍如何在 Windows 上安装 C23 工具链、添加官方项目模板、在 声明式 与 命令式 两条路线之间做出选择，以及编译并运行第一个 Xent 0.3.3 应用程序。

第 1 步：安装工具链¶

在 Windows 上构建 Xent C 应用需要 Windows 10 1903 及以上版本 、 git 、 Xmake 3.1.2+ 以及 llvm-mingw C23 编译工具链。

  1. 安装 Xmake（3.1.2 及以上版本） ：按照官方 Xmake 安装指南 完成安装，并安装 Git 以便 Xmake 拉取依赖仓库。

  2. 安装 llvm-mingw（UCRT 版） ：Xent 在 Windows 上以 llvm-mingw Clang 作为主力 C23 工具链。前往官方仓库 mstorsjo/llvm-mingw ，从 llvm-mingw Releases 下载对应架构的 Windows 原生 UCRT .zip 压缩包：

    • 64 位 x86 Windows： llvm-mingw-<date>-ucrt-x86_64.zip

    • ARM64 Windows： llvm-mingw-<date>-ucrt-aarch64.zip

    将压缩包解压到固定目录（例如 C:\llvm-mingw ），并将其中的 bin 目录（ C:\llvm-mingw\bin ）加入当前用户的 PATH 环境变量。

重新打开一个终端窗口，验证以下三条命令均能输出版本号：

xmake --version
git --version
x86_64-w64-mingw32-clang --version

第 2 步：安装项目模板¶

Project Xent 通过 Xmake Addon 分发开箱即用的 C23 工程模板。为当前用户安装一次 xent-repo 插件并查看可用模板列表：

xmake addon -i github:Project-Xent/xent-repo
xmake create --list

在 c 语言分类下包含两个 Fluxent 工程模板：

  • fluxent.decl —— 声明式应用模板（ flux_run ）

  • fluxent.imp —— 命令式应用模板（ XtkScene / XtkTxn ）

第 3 步：声明式与命令式——对比与选型¶

fluxent.decl 与 fluxent.imp 共享同一个保留式 Fluxent 宿主、原生 Direct2D/DirectWrite 控件、无障碍支持以及原子化 XtkBatch 提交引擎。请根据应用场景选择适合的编程模型：

对比维度

声明式（ fluxent.decl ）

命令式（ fluxent.imp ）

编程模型

由 flux_run 驱动的单向 Model–View–Update（MVU）循环。

持有保留式 XtkScene 句柄，通过原子化 XtkTxn 事务与 C 事件回调驱动。

入口函数与头文件

flux_run(&cfg, &model, update, view) ，配合 <fluxent/fluxent.h> 与 <xtk/xtk.h> 构建器。

flux_app_create + flux_app_attachhost + xtk_scene_fromhost ，配合 <xtk/xtk_controls.h> 。

界面构建与更新方式

view() 根据当前 Model 返回轻量 XtkEl * 描述树，协调器自动计算并提交最小 XtkBatch 变更。

开启 XtkTxn 事务，通过带 .set 位掩码的 xtk_*_create 创建控件、保存 XtkCtrl 句柄，并直接调用 xtk_*_set* 更新属性。

事件处理

控件投递 XtkMsg 消息值，所有状态转移集中在 update(model, msg) 函数中完成。

控件触发由 xtk_*_on* 或 xtk_txn_on 绑定的 XtkEventFn 回调函数，在回调中标记脏状态并更新目标控件。

优势

代码简明；界面与状态自动保持一致；自动管理控件生命周期；条件分支与动态布局直观清晰。

按属性定点直写；显式掌控事务边界与 XtkCtrl 句柄生命周期；同时也是多语言绑定所使用的稳定 C ABI。

需要权衡之处

在每批消息处理后重新求值 view() （大型静态子树可通过 xtk_memo_region 或 xtk_static_region 缓存复用）。

需要显式填写 .set 属性位掩码、将 XtkLocalId 解析为 XtkCtrl 句柄，并手动维护状态到控件的同步。

选型建议¶

  • 默认优先选择声明式（ fluxent.decl ） ：适合初次上手 Xent，以及开发桌面应用、表单、设置面板、多步向导与各类开发工具。

  • 在以下场景选择命令式（ fluxent.imp ） ：需要将 Xent 接入已有的回调驱动或帧驱动 C 引擎、每帧对少量控件执行高频定点属性写入，或基于 Xent C ABI 编写其他语言绑定。

第 4 步：创建项目、安装依赖、编译并运行第一个应用¶

使用所选模板生成新项目（声明式使用 -t fluxent.decl ，命令式使用 -t fluxent.imp ）：

xmake create -l c -t fluxent.decl hello
cd hello

该命令会自动生成配置好 C23 标准、 xent-repo 包仓库与 Windows 窗口子系统的 xmake.lua 和 src/main.c 。

将 Xmake 工具链指向解压后的 llvm-mingw 根目录（即包含 bin 的上一级目录，例如 C:\llvm-mingw ）：

xmake f -p mingw -a x86_64 --mingw="C:\llvm-mingw" -m debug -y

（在 ARM64 Windows 上请传入 -a arm64 。）

安装 xmake.lua 中声明的项目依赖—— xmake require 会自动下载并编译 fluxent 0.3.3 及其传递依赖（ xent-kit 0.3.3 、 xent-core 0.3.3 与 cwinrt 0.3.1 ）：

xmake require

小技巧

首次执行 xmake require 会从源码编译并缓存这四个包。随时可运行 xmake require --list 查看已安装的依赖包与版本。

编译并运行应用：

xmake
xmake run

此时会打开一个带 Mica 材质、标题为 hello 的原生窗口，包含 Counter 标题、 Value: 0 以及 − 、 + 、 Reset 按钮。后续修改 src/main.c 后，只需执行 xmake 与 xmake run 即可增量编译运行；当更新 xmake.lua 中的 add_requires 时再运行一次 xmake require 。
