声明式开发指南¶

声明式路线 （ fluxent.decl ）围绕 flux_run 与 <xtk/xtk.h> 中的元素构建器开发原生 Windows 应用。代码将应用状态存放在普通 C struct 中，在 update() 中处理带整数标签的消息，在 view() 中描述当前界面结构，并由协调器对底层保留式控件执行增量更新。

从零上手建议按章节顺序阅读，也可按页面需求直接查阅对应控件分类：

  1. 1. Elm MVU 循环与应用结构 —— 理解 Elm Model–View–Update 循环，逐行拆解 fluxent.decl 模板，组织大型消息分发表、注册控件模块并管理帧内存池动态字符串。

  2. 2. 布局容器、文本排版与图像媒体 —— 使用 Flex 堆栈容器、卡片、布局修饰器、受控 ScrollViewer 视口、可继承文本样式与异步 WIC 图像编排界面。

  3. 3. 表单输入、选择器与受控状态 —— 处理按钮、开关、滑块、本地化 NumberBox 、受控 TextBox / AutoSuggestBox 文本编辑，以及日期、时间、日历与颜色选择器。

  4. 4. 虚拟化列表、网格、树视图与子树缓存 —— 渲染 10 万行级虚拟化 ListView 与 GridView 、吸顶分组标题、可排序拖拽列头、层级 TreeView 、节点键（Key）与缓存区域。

  5. 5. 多页导航、工具栏与模态弹层 —— 使用 NavigationView 、 TabView 、 SplitView 、自定义 TitleBar 、 CommandBar 溢出工具栏、模态 ContentDialog 、 TeachingTip 与状态栏搭建多页应用外壳。

  6. 6. 文件对话框、拖放、主题切换与后台线程 —— 获取 FluxApp * 调用原生文件对话框、OLE 拖放、剪贴板读写、实时主题与背景材质切换以及后台工作线程通信。
