5. 多页导航、工具栏与模态弹层¶

完整的桌面应用通常包含多页侧边导航外壳、多文档标签页、命令工具栏与模态确认对话框——在声明式模式下，它们全部直接由 Model 字段驱动。

使用 NavigationView 搭建多页应用外壳¶

xtk_nav （需注册 &flux_ctrl_nav ）提供完整的 WinUI NavigationView ，包含可折叠侧边栏、分类标题、分隔线、底部固定项以及可选的一体化自定义窗口标题栏：

enum {
    PAGE_HOME = 0,
    PAGE_PROJECTS,
    PAGE_SEP_1,
    PAGE_SETTINGS,
    PAGE_COUNT
};

static XtkNavItemDesc const kNavItems[PAGE_COUNT] = {
    [PAGE_HOME]     = {.kind = XTK_NAV_ITEM,      .icon = "Home",     .label = "Home"},
    [PAGE_PROJECTS] = {.kind = XTK_NAV_ITEM,      .icon = "Folder",   .label = "Projects"},
    [PAGE_SEP_1]    = {.kind = XTK_NAV_SEPARATOR},
    [PAGE_SETTINGS] = {.kind = XTK_NAV_FOOTER,    .icon = "Settings", .label = "Settings"},
};

static XtkEl *active_page(XtkUi *ui, Model const *m) {
    switch (m->page) {
    case PAGE_PROJECTS : return view_projects(ui, m);
    case PAGE_SETTINGS : return view_settings(ui, m);
    default            : return view_home(ui, m);
    }
}

static XtkEl *view(XtkUi *ui, void *model) {
    Model const *m = model;
    XtkEl *body = xtk_grow(
        xtk_keyed_u64(
            xtk_scroll(
                ui, (XtkScrollDesc) {0},
                xtk_kids(xtk_column(
                    ui, (XtkStackDesc) {.padding = {36, 28, 36, 28}, .gap = 20, .align = XENT_FLEX_ALIGN_STRETCH},
                    xtk_kids(active_page(ui, m))
                ))
            ),
            (uint64_t) m->page
        ),
        1.0f
    );

    return xtk_grow(
        xtk_nav(
            ui,
            (XtkNavDesc) {
                .items            = kNavItems,
                .nitem            = PAGE_COUNT,
                .sel              = m->page,
                .window_title_bar = true,
                .app_title        = "My Xent App",
                .select           = xtk_msg(MSG_NAV_SELECT),
            },
            xtk_kids(body)
        ),
        1.0f
    );
}

使用 xtk_keyed_u64(..., m->page) 包裹页面滚动容器可为每个路由赋予独立的滚动视口，切换页面时各自保持干净的初始滚动位置。

SplitView 分栏与自定义 TitleBar¶

如需单独定制可折叠侧边抽屉或自定义无边框窗口标题栏，可使用：

  • xtk_splitview(ui, desc, pane_el, content_el) （ &flux_ctrl_splitview ）——支持左侧（ XTK_SPLITVIEW_LEFT ）或右侧（ RIGHT ）面板，提供 XTK_SPLITVIEW_INLINE 、 COMPACT_INLINE 、 OVERLAY 与 COMPACT_OVERLAY 四种展示模式。

  • xtk_titlebar(ui, "App Title", desc) （ &flux_ctrl_titlebar ）——设置 .integrate_window = true 即可接管原生 Win32 标题栏，绘制支持 Windows 贴靠布局（Snap Layouts）的最小化/最大化/关闭按钮、处理窗口拖拽区域，并投递 .on_back 与 .on_pane_toggle 消息。

多文档 TabView 、 SelectorBar 与 Expander¶

  • 可新建与关闭的标签页 （ xtk_tabs ， &flux_ctrl_tab ）：将打开的文档列表与当前激活下标保存在 Model 中，构造 XtkTabDesc 标题数组并将当前激活文档的视图作为子元素传入：

    XtkTabDesc headers[16];
for (int i = 0; i < m->tab_count; i++) {
    headers[i] = (XtkTabDesc) {.icon = "Document", .label = m->tabs[i].title};
}

xtk_tabs(
    ui,
    (XtkTabViewDesc) {
        .tabs   = headers,
        .ntab   = m->tab_count,
        .sel    = m->active_tab,
        .select = xtk_msg(MSG_TAB_SELECT), // msg.i = clicked tab index
        .close  = xtk_msg(MSG_TAB_CLOSE),  // msg.i = closed tab index
        .add    = xtk_msg(MSG_TAB_NEW),
    },
    xtk_kids(m->tab_count > 0 ? view_document(ui, &m->tabs[m->active_tab]) : NULL)
)

  • 分段切换、面包屑与折叠面板 ： xtk_selector 用于轻量横向视图切换； xtk_breadcrumb 渲染可点击路径层级（在 msg.i 中返回点击段下标）； xtk_expander 提供由 .expanded 与 .toggle 控制的可折叠卡片； xtk_flip / xtk_pips / xtk_pager 用于分页轮播与页码切换。

MenuBar 菜单栏与 CommandBar 命令栏（0.3.3）¶

  • 桌面菜单栏 （ xtk_menubar ， &flux_ctrl_menubar ）：接收 XtkMenuDesc 顶层菜单数组（如 File 、 Edit 、 View ），每个菜单包含一组带 .click 消息的 XtkMenuItemDesc 条目。

  • Fluent 命令栏 （ xtk_commandbar ，需注册 &flux_ctrl_commandbar 、 &flux_ctrl_appbarbutton 、 &flux_ctrl_appbartoggle 、 &flux_ctrl_appbarsep ）：在工具栏上展示主操作按钮，将 .secondary = true 的次级命令收入 ... 溢出菜单，并在开启 .dynamic = true 时随窗口变窄自动将主命令折叠进溢出菜单：

    xtk_commandbar(
    ui,
    (XtkCommandBarDesc) {.labels = XTK_LABEL_RIGHT, .dynamic = true},
    xtk_kids(
        xtk_appbarbutton(ui, "New",  (XtkAppBarDesc) {.icon = "Add",  .accel = "Ctrl+N", .click = xtk_msg(MSG_NEW)}),
        xtk_appbarbutton(ui, "Save", (XtkAppBarDesc) {.icon = "Save", .accel = "Ctrl+S", .click = xtk_msg(MSG_SAVE)}),
        xtk_appbarsep(ui, (XtkAppBarDesc) {0}),
        xtk_appbartoggle(ui, "Wrap", (XtkAppBarDesc) {.icon = "AlignLeft", .checked = m->word_wrap, .change = xtk_msg(MSG_WRAP)}),
        xtk_appbarbutton(ui, "Export PDF…", (XtkAppBarDesc) {.secondary = true, .click = xtk_msg(MSG_EXPORT_PDF)})
    )
)

模态 ContentDialog 、 TeachingTip 与状态反馈控件¶

声明式 Xent 中的弹出层直接由 Model 中的布尔标志控制——将 xtk_dialog 或 xtk_teachtip 放入 view() 树并切换 .open ：

// In update():
case MSG_ASK_DELETE:
    m->confirm_open = true;
    break;
case MSG_CONFIRM_RESULT:
    m->confirm_open = false;
    if (msg.i == 1) {          // 1 = primary, 2 = secondary, 0 = close/cancel
        delete_selected_item(m);
    }
    break;

// In view() (register &flux_ctrl_dialog):
xtk_dialog(
    ui, "Delete project?",
    (XtkDialogDesc) {
        .open      = m->confirm_open,
        .primary   = "Delete",
        .secondary = "Archive instead",
        .close     = "Cancel",
        .w         = 420.0f,
        .contenth  = 64.0f,
        .result    = xtk_msg(MSG_CONFIRM_RESULT),
    },
    xtk_kids(
        xtk_text(ui, "Removing this project deletes local build caches permanently.", (XtkTextDesc) {.size = 14})
    )
)

  • 教学提示气泡 （ xtk_teachtip ， &flux_ctrl_teachtip ）：支持 .subtitle 、 .action_text 、 .on_action 、 .light_dismiss = true 轻点外部关闭以及 .close 消息的非模态浮层。

  • 状态与进度反馈 ： xtk_infobar 提供 XTK_INFOBAR_INFORMATIONAL 、 SUCCESS 、 WARNING 、 ERROR 四种级别的消息横幅（支持 .closable 关闭按钮）； xtk_progress 提供确定进度或 .indeterminate = true 进度条（支持 XTK_PROGRESS_NORMAL / PAUSED / ERROR 状态色）；以及 xtk_progressring 进度环和 xtk_badge 角标。
