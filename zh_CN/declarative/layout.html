2. 布局容器、文本排版与图像媒体¶

Xent 声明式布局由 Flex 堆栈容器、布局修饰器、可滚动视口、继承式文本排版与异步 WIC 图像组合而成。

Flex 堆栈容器、卡片与 xtk_kids¶

四类常用构建器用于组织子元素与间隔：

  • xtk_column(ui, desc, children) —— 纵向排列子元素（主轴自上而下，交叉轴水平）。

  • xtk_row(ui, desc, children) —— 横向排列子元素（主轴自左向右，交叉轴垂直）。

  • xtk_card(ui, desc, children) —— 带主题背景色、圆角与描边边框的纵向 Fluent 卡片容器。

  • xtk_divider(ui) 与 xtk_spacer(ui) —— 堆栈内的视觉分隔线与弹性空白占位项。

使用 xtk_kids(...) 包裹内联子元素列表，它会自动构造以 XTK_END 哨兵结尾的复合字面量数组：

xtk_card(
    ui,
    (XtkStackDesc) {
        .gap     = 12,
        .padding = {20, 16, 20, 16},
        .align   = XENT_FLEX_ALIGN_STRETCH,
    },
    xtk_kids(
        xtk_text(ui, "Storage", (XtkTextDesc) {.size = 18, .weight = XTK_FONT_SEMI_BOLD}),
        xtk_divider(ui),
        xtk_row(
            ui, (XtkStackDesc) {.gap = 8, .align = XENT_FLEX_ALIGN_CENTER},
            xtk_kids(
                xtk_text(ui, "System drive (C:)", (XtkTextDesc) {0}),
                xtk_grow(xtk_spacer(ui), 1.0f),
                xtk_text(ui, "142 GB free", (XtkTextDesc) {0})
            )
        )
    )
)

XtkStackDesc 字段说明¶

字段

作用

.gap

相邻可见子元素之间的逻辑像素间距。

.padding

按 {left, top, right, bottom}``（左、上、右、下）顺序排列的 ``XentInsets 内边距。

.align

交叉轴对齐方式： XENT_FLEX_ALIGN_START 、 CENTER 、 END 或 STRETCH 。

.justify

主轴空间分布： XENT_FLEX_JUSTIFY_START 、 CENTER 、 END 、 SPACE_BETWEEN 、 SPACE_AROUND 或 SPACE_EVENLY 。

.wrap

默认 XENT_FLEX_NO_WRAP ；设为 XENT_FLEX_WRAP 时支持多行自动折行（如标签组或流式工具栏）。

.fill

使容器扩展以填满父容器的可用空间。

尺寸与布局修饰器¶

修饰器函数接收一个 XtkEl * 并为其附加布局约束：

  • xtk_sized(el, width, height) —— 按逻辑像素指定宽度、高度或同时指定两者；引入 <math.h> 后对按内容自适应的轴传入 NAN （例如 xtk_sized(btn, 120.0f, NAN) ）。

  • xtk_grow(el, factor) —— 设置沿父堆栈主轴的 Flex 伸展权重。使用 xtk_grow(..., 1.0f) 包裹根容器或主内容区即可让它铺满窗口。

  • xtk_align(el, XENT_FLEX_ALIGN_...) —— 单独覆盖某个子元素的交叉轴对齐（例如在左对齐纵列中用 XENT_FLEX_ALIGN_END 让底部按钮靠右对齐）。

  • xtk_margin(el, (XentInsets) {left, top, right, bottom}) —— 为元素四周添加外边距。

  • xtk_tooltip(ui, el, "Save Ctrl+S") —— 附加鼠标悬停与键盘焦点提示框（需注册 &flux_ctrl_tooltip ）。

可滚动视口与受控滚动¶

使用 xtk_scroll （需注册 &flux_ctrl_scroll ）包裹长页面内容，即可获得 DirectManipulation 触控板惯性滚动与主题滚动条：

xtk_grow(
    xtk_scroll(
        ui, (XtkScrollDesc) {0},
        xtk_kids(
            xtk_column(
                ui, (XtkStackDesc) {.padding = {32, 24, 32, 24}, .gap = 16, .align = XENT_FLEX_ALIGN_STRETCH},
                xtk_kids(/* page content */)
            )
        )
    ),
    1.0f
)

自动跟随底部的日志视口¶

XtkScrollDesc 支持由 Model 驱动滚动偏移，非常适合实时构建日志或聊天消息面板：

  • 某个轴向传入 NAN 时完全交由用户滚动；传入具体像素偏移时由 Model 受控驱动；在 .y 上传入 INFINITY 时会在新行追加时自动吸附到底部。

  • 绑定 .scroll = xtk_msg(MSG_LOG_SCROLL) 后， update() 中的 msg.f 会收到当前纵向滚动位置，而当视口贴底时 msg.b 为 true ——用户向上翻阅时自动暂停跟随，滚回底部后自动恢复跟随：

    // In update():
case MSG_LOG_SCROLL:
    m->log_follow = msg.b;
    m->log_y      = msg.f;
    break;

// In view():
xtk_scroll(
    ui,
    (XtkScrollDesc) {.x = NAN, .y = m->log_follow ? INFINITY : m->log_y, .scroll = xtk_msg(MSG_LOG_SCROLL)},
    xtk_kids(xtk_text(ui, m->log_buffer, (XtkTextDesc) {.size = 12, .selectable = true}))
)

文本排版与样式继承¶

xtk_text(ui, content, desc) 使用 DirectWrite 渲染排版完整的 Unicode 文本：

  • 字号与字重继承（0.3.3） ：保持 .size = 0 或 .weight = XTK_FONT_INHERIT 时，会自动继承最近祖先节点的字号与字重（根节点默认为 14.0f 与 XTK_FONT_REGULAR ）。标题与小节头可显式指定如 .size = 28, .weight = XTK_FONT_SEMI_BOLD 。

  • 自动换行、行数限制与省略号 ：文本默认按容器宽度自动折行。设置 .nowrap = true 或 .max_lines = 2 并配合 .trim = XTK_TRIM_CHAR_ELLIPSIS 、 XTK_TRIM_WORD_ELLIPSIS 或 XTK_TRIM_PATH_ELLIPSIS （适合长文件路径中间/路径级省略）可控制截断方式。

  • 可选中文本 ：在只读输出、错误详情或日志区域上设置 .selectable = true ，用户即可拖拽框选文本并按 Ctrl+C 复制。

  • 文本颜色 ：在 .color 中传入 XtkColor （保持零初始化则自动使用当前深浅色主题的主文本画刷）。

图像、SVG、动图与九宫格拉伸¶

xtk_image （需注册 &flux_ctrl_image ）在后台线程池上异步解码位图、GIF 动图、APNG 与矢量 SVG：

XtkResource logo = flux_image_respath("assets/logo.svg");

xtk_sized(
    xtk_image(ui, (XtkImageDesc) {
        .source  = logo,
        .stretch = XTK_IMAGE_UNIFORM,
        .opened  = xtk_msg(MSG_IMG_READY),
        .failed  = xtk_msg(MSG_IMG_ERROR),
    }),
    160.0f, 160.0f
)

  • flux_image_respath(path) 对 UTF-8 文件路径做驻留并返回进程生命周期内有效的 XtkResource 资源句柄。

  • 缩放模式 ：支持 XTK_IMAGE_UNIFORM （保持宽高比适应边界）、 XTK_IMAGE_FILL （双向拉伸填满）、 XTK_IMAGE_UNIFORM_TO_FILL （等比填满并裁剪溢出部分）与 XTK_IMAGE_NONE 。省略 xtk_sized 时，图像在头部异步解析完成后按其自然像素尺寸参与排版。

  • 九宫格切片 ：配合 XTK_IMAGE_FILL 设置 .nine = {left, top, right, bottom} 可保持四角原尺寸并拉伸四边与中心区域。

  • 头像控件 ： xtk_avatar （需注册 &flux_ctrl_avatar ）可根据 .image 、 .initials 或 .display_name 渲染圆形 PersonPicture 头像及状态角标。
