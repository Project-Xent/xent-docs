3. 表单输入、选择器与受控状态¶

在声明式 Xent 中，表单控件在 view() 里从 Model 读取当前值，并通过 XtkMsg 载荷将用户的修改传回 update() 。

XtkMsg 载荷字段速查表¶

每种交互控件在投递自定义消息 tag 时，会将新值写入 XtkMsg 的对应载荷字段：

控件构建函数

描述结构体字段

update() 中读取的载荷字段

xtk_button / xtk_repeat / xtk_link

.click

msg.tag （用 xtk_msg_i 构造时可同时读取 msg.i ）

xtk_checkbox / xtk_switch / xtk_radio

.change

msg.b （ bool 选中状态）

xtk_checkbox （三态复选框）

.change_state

msg.i （ 0 未选、 1 选中、 2 半选）

xtk_slider

.change / .change_range

单值滑块读取 msg.f ；范围滑块从 msg.f 读取起点、从 (float) msg.d 读取终点

xtk_number / xtk_rating / xtk_scroll_bar

.change

msg.d （ double 数值）

xtk_combo / xtk_radiogroup / xtk_looping_selector

.select

msg.i （ int32_t 选中项下标）

xtk_textbox / xtk_password / xtk_combo （ .submit ）

.change / .submit

(char const *) msg.ptr （借用的 UTF-8 字符串，在 update() 内用 strdup 拷贝保存）

xtk_suggest

.on_text / .query / .on_chosen

.on_text 与 .query 读取 msg.ptr （UTF-8 文本）； .on_chosen 读取 msg.i （建议项下标）

xtk_date_picker / xtk_calendar_view

.change / .select

msg.i 为 YYYYMMDD 编码日期（见 xtk_date ）；日历控件同时通过 msg.b 表示选中或取消选中

xtk_time_picker

.change

msg.i （自零点起的分钟数， 0 – 1439 ）

xtk_color_picker

.change

(uint32_t) msg.i 打包的 ARGB 颜色值

按钮、超链接与下拉菜单按钮¶

  • 标准与样式按钮 （ &flux_ctrl_button ）： xtk_button 支持 XTK_BUTTON_STANDARD （ 0 ）、 XTK_BUTTON_ACCENT 、 XTK_BUTTON_SUBTLE 与 XTK_BUTTON_TEXT 四种样式，并可在 .icon 中填写 Fluent 图标名（如 "Save" 、 "Share" 、 "Delete" 、 "Settings" ；将标签设为 NULL 即为纯图标按钮）。

  • 连发按钮与超链接 ： xtk_repeat （ &flux_ctrl_repeat ）在按住期间连续触发 .click ； xtk_link （ &flux_ctrl_link ）可打开 .url 链接或发送 .click 消息。

  • 下拉、拆分与切换拆分按钮 （ &flux_ctrl_dropdown 、 &flux_ctrl_split 、 &flux_ctrl_togglesplit ）：通过 XtkMenuItemDesc 数组挂载弹出菜单：

    static XtkMenuItemDesc const kExportItems[] = {
    {.label = "Export PNG", .icon = "Save",  .click = {.tag = MSG_EXPORT, .i = 0}},
    {.label = "Export SVG", .icon = "Share", .click = {.tag = MSG_EXPORT, .i = 1}},
};

xtk_split(ui, "Export", (XtkSplitDesc) {
    .icon  = "Save",
    .click = xtk_msg_i(MSG_EXPORT, 0),
    .items = kExportItems,
    .nitem = 2,
})

开关、单选按钮组与数值控件¶

static XtkRadioItem const kThemes[] = {
    {.label = "Use system setting"},
    {.label = "Light"},
    {.label = "Dark"},
};

xtk_column(ui, (XtkStackDesc) {.gap = 14}, xtk_kids(
    xtk_checkbox(ui, "Launch at sign-in", (XtkToggleDesc) {
        .checked = m->autostart,
        .change  = xtk_msg(MSG_AUTOSTART),
    }),
    xtk_switch(ui, (XtkToggleDesc) {
        .checked = m->notifications,
        .change  = xtk_msg(MSG_NOTIFY),
    }),
    xtk_radiogroup(ui, (XtkRadioButtonsDesc) {
        .header      = "App theme",
        .items       = kThemes,
        .nitem       = 3,
        .sel         = m->theme_idx,
        .max_columns = 1,
        .select      = xtk_msg(MSG_THEME),
    }),
    xtk_sized(xtk_number(ui, (XtkNumberDesc) {
        .min    = 1.0,
        .max    = 64.0,
        .step   = 1.0,
        .value  = m->worker_threads,
        .change = xtk_msg(MSG_THREADS),
    }), 180.0f, NAN),
    xtk_sized(xtk_slider(ui, (XtkSliderDesc) {
        .min    = 0.0f,
        .max    = 100.0f,
        .step   = 5.0f,
        .value  = m->volume,
        .change = xtk_msg(MSG_VOLUME),
    }), 240.0f, NAN)
))

记得注册对应的控件模块（ &flux_ctrl_checkbox 、 &flux_ctrl_switch 、 &flux_ctrl_radiogroup 、 &flux_ctrl_number 、 &flux_ctrl_slider ），或直接调用 flux_controls_all() 。

受控文本编辑与 AutoSuggestBox¶

xtk_textbox （ &flux_ctrl_textbox ）与 xtk_password （ &flux_ctrl_password ）内置完整的 DirectWrite 字素光标移动、撤销/重做、剪贴板快捷键与中日韩输入法（IME）组字支持。

msg.ptr 仅在 update() 执行期间借用有效，请将其拷贝到由 Model 持有的堆内存或固定缓冲区中：

static void replace_str(char **slot, char const *next) {
    free(*slot);
    *slot = next ? strdup(next) : NULL;
}

// In update():
case MSG_SEARCH_TEXT:
    replace_str(&m->query, (char const *) msg.ptr);
    rebuild_suggestions(m);
    break;
case MSG_SEARCH_CHOSEN:
    if (msg.i >= 0 && msg.i < m->suggestion_count) {
        replace_str(&m->query, m->suggestions[msg.i]);
    }
    break;

// In view() (register &flux_ctrl_suggest):
xtk_sized(
    xtk_suggest(ui, "Search commands…", (XtkAutoSuggestDesc) {
        .content     = m->query,
        .suggestions = (char const *const *) m->suggestions,
        .nitem       = m->suggestion_count,
        .query_icon  = "Find",
        .on_text     = xtk_msg(MSG_SEARCH_TEXT),
        .query       = xtk_msg(MSG_SEARCH_SUBMIT),
        .on_chosen   = xtk_msg(MSG_SEARCH_CHOSEN),
    }),
    320.0f, NAN
)

Fluxent 宿主会自动追踪各变更源的 XtkChangeStamp 版本戳：把 m->query 传回 .content 既能让外部重置立即生效，又能在用户连续打字时完好保留正在进行的输入法组字状态与光标选区。

需要多行文本编辑或只读文本框时，在 XtkTextBoxDesc 上设置 .multiline = true 或 .readonly = true 。

下拉框、日期、时间、日历与颜色选择器¶

  • ComboBox 下拉框 （ xtk_combo ， &flux_ctrl_combo ）：通过 .items 、 .nitem 与 .sel 传入选项列表和当前索引；设置 .editable = true 并绑定 .submit = xtk_msg(MSG_CUSTOM_VALUE) 可同时支持自由输入文本。

  • 日期与日历 （ xtk_date_picker / xtk_calendar_view ）：日期使用 xtk_date(year, month, day) 编码为 int32_t 整数（ year * 10000 + month * 100 + day ，例如 20261118 ）；在 update() 中通过 year = d / 10000 、 month = (d / 100) % 100 、 day = d % 100 解码。

  • 时间选择器 （ xtk_time_picker ）： .minutes 保存自 00:00 起的分钟数（ hours * 60 + mins ），配合 .has_time = true 与 .clock = XTK_CLOCK_24H 或 XTK_CLOCK_12H 使用。

  • 颜色选择器 （ xtk_color_picker ）：通过 .color 传入 XtkColor ，支持 .alpha = true 透明通道滑块与 .spectrum 色谱形状，并在变更时将 32 位 ARGB 整数写入 msg.i 。
